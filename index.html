jev-game

비공개 저장소Node

Jev가 체스를 둡니다. 수를 몇 수 앞까지 읽는 계산이 없는 모델이 어디까지 가는지 봅니다.

  • 모드: Jev vs Stockfish, Jev vs Jev, 사람 vs Jev
  • Stockfish 난이도 사다리 벤치마크: 승·무·패, 추정 Elo, 수 품질(ACPL)·블런더
  • 전술 힌트 조건(없음 / 규칙 계산 / Jev 계산)과 전략 지시문 편집기
  • 국면 문제집(52문제)으로 Jev와 일반 LLM 비교
저장소

jev-benchmark

비공개 저장소Python

Jev가 원래 겨냥하는 판정 과제에서 일반 LLM과 비교합니다. 같은 입력, 같은 질문, 같은 판정 규칙을 씁니다.

  • 판정 과제 10종, 케이스 83개: 수집 가치, 민감정보, 프롬프트 인젝션, RAG 관련성, 도구 호출 게이트, 보안 경보 분류 등
  • 지표: 정확도, 비싼 실수, 무효 응답, 평균·p95 지연, 1,000건당 비용
  • 웹 화면(키 입력창)과 CLI, 키 없이 실제 Jev 기록을 재생하는 모드
저장소

jev-ingest-filter

비공개 저장소Python

jev-benchmark의 과제 원본입니다. 파이프라인 앞단 판정 필터로 Jev를 쓰는 유즈케이스를 정의하고 실제 Jev로 실행한 결과를 담았습니다.

  • 유즈케이스마다 질문, 판정 규칙, 비싼 실수 기준, 합성 케이스
  • 정규식 규칙과 Jev 비교, 입력 길이에 따른 토큰·한도 측정
저장소

지금까지 관찰한 것

  • 판정 과제: 합성 케이스 83건에서 정답률 94%, 비싼 실수 1건, 평균 0.29초, 1,000건당 $0.022 (2026-09-28 실행 기록 기준).
  • 체스, 힌트 없음: 무작위로 두는 상대와 둔 판이 무승부로 끝났습니다. "백이 크게 우세"라고 판단하면서 킹 옆에 퀸을 공짜로 내준 수가 결정적이었습니다 (한 판 관찰).
  • 체스, 규칙 계산 힌트: 코드가 계산한 "이 수를 두면 무엇을 잃는가"를 선택지에 붙이자 직접 둔 대국에서 승률이 눈에 띄게 올랐습니다 (수치는 아직 집계 전).
  • 정리: Jev는 주어진 사실로 빠르게 판정하는 데 강합니다. 몇 수 앞을 읽는 계산은 코드가 하고 판단만 Jev에게 맡기는 구조가 맞습니다.
