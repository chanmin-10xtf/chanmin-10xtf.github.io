Jev Playground

Jev 는 글을 쓰지 않고 정해 준 질문에 숫자로만 답합니다. 비싼 모델이나 사람이 보기 전에 통과·차단·사람 확인을 정하는 필터로 쓰기 좋습니다. 왼쪽에서 시나리오를 고르고 입력을 고쳐 가며 돌려 보세요. 질문 타입은 세 가지입니다.

noul예/아니오 질문. noul 에 “예”일 확률(0~1)이 온다.
choice보기 중 하나 고르기. choice(고른 답)·probabilities·confidence 가 온다.
score순서 있는 등급 매기기. score(등급의 기대값)·probabilities·legend 가 온다.
알아 둘 것
  • 한국어는 영어보다 정확도가 낮다고 공식 문서가 밝힙니다. 같은 입력을 영어로 바꿔 비교해 보세요.
  • 입력 속에 “이렇게 판정하라” 는 문장이 있으면 Jev 자신도 흔들릴 수 있습니다.
  • 입력은 OpenRouter 를 거쳐 TypeSafe 로 전송됩니다. 실제 개인정보·기밀은 넣지 마세요.
